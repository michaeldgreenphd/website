# Python dependencies for the data refresh workflow
# (.github/workflows/update-scholar.yml). Every package is pinned, including
# transitive ones, to the versions of the last green run (2026-09-07). On
# 2026-09-08 an unpinned transitive dependency, bibtexparser 2.0.0, dropped
# the module scholarly imports (bibtexparser.bibdatabase) and the Scholar
# fetch failed; direct pins alone cannot prevent that. Bump one line at a
# time and watch the next run; changing this file runs the workflow on the
# branch that carries the change.
#
# Each pin also lists the sha256 hashes of the files the runner can install:
# the sdist, and each wheel for CPython 3.12 on Linux x86_64 or pure Python.
# The workflow installs with --require-hashes, so a file added to (or
# swapped in) an old release later is refused. setuptools, which builds the
# two sdist-only pins (free-proxy, bibtexparser), is pinned the same way in
# build-requirements.txt and used with --no-build-isolation. When bumping a
# pin, replace its hash lines with the new release's values from
# https://pypi.org/pypi/<name>/<version>/json (the digests.sha256 of the
# sdist and of those wheels); a missing or wrong hash fails the install
# rather than installing anything else. Keep a comment on the last hash
# line of its entry: a "#" before a trailing backslash would hide the
# hashes that follow it.
